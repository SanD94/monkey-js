# monkey-js

A collection of userscripts for [Violentmonkey](https://violentmonkey.github.io/).

## Scripts

### YouTube Playlist to Markdown

[`youtube-playlist.user.js`](./youtube-playlist.user.js) adds a **Download playlist (.md)** command to Violentmonkey on YouTube playlist pages. The command loads the full playlist and downloads a numbered Markdown list of its videos.

## Installation

1. Install the Violentmonkey extension for your browser.
2. Open the `.user.js` file you want to install from this repository.
3. Select **Raw** to open the script in Violentmonkey.
4. Review the script and select **Confirm installation**.

Installed scripts can be managed from the Violentmonkey dashboard.

## Adding scripts

Keep each userscript in the repository root and name it with the `.user.js` suffix so Violentmonkey recognizes it.
